# Changelog

## 0.1.0

Initial public product baseline:

- Reproducible campaign planning and local execution with SQLite persistence and content-addressed artifacts.
- LHS and optional TPE tuning with multi-objective Pareto results and per-run worst-case constraints.
- Local MCP stdio server with workspace boundaries, backend allowlist, and bounded campaign budgets.
- Synthetic tutorial backend and pinned Nav2/TurtleBot3 Docker example.
- Versioned robot capability profiles, metrics catalog, reports, and backend-authoring guide.
